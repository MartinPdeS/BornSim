36 Parameters 

37 ---------- 

38 source : Source

40 sampling : AngularSampling, optional 

41 Shared output angles and solid-angle quadrature. Defaults to

43 order : int, optional 

44 Highest cumulative numerical Born order, from 1 to 12. Default is 3. 

45 Analytical calculations always use first order. 

46 quadrature_order : int, optional 

47 Gauss-Legendre order for analytical integrated coefficients. Must be 

48 at least 16; default is 256. Numerical integration uses sampling's 

49 polar_samples and azimuth_samples instead.

51 Attributes 

52 ----------

54 Incident source shared by all calculations. 

55 order : int 

56 Highest numerical Born order. 

57 quadrature_order : int 

58 Analytical integration order. 

59 

60 Raises 

61 ------ 

62 TypeError 

63 If ``source`` is not a Source. 

64 ValueError 

65 If either order parameter is outside its supported integer range. 

66 

67 Notes 

68 ----- 

69 Numerical calculations retain the linearized dielectric contrast 

70 ``2 * n0 * delta_n``. Green-tensor self interactions use an equal-volume 

71 sphere including the longitudinal contact term. Increasing Born order 

72 does not restore the omitted quadratic constitutive term. Decreasing 

73 successive terms do not establish universal Born convergence.

330 sampling : AngularSampling, optional 

331 Override shared angular settings. Defaults to the solver's sampling 

332 when individual angular keywords are omitted. Cannot be combined 

333 with angles, polar_samples, or azimuth_samples. 

334 shape : tuple of int, optional 

335 Three grid dimensions, each from 2 to 32. Default is (12, 12, 12). 

336 spacing : float or Quantity, optional 

337 Positive, finite cubic voxel spacing. Bare values mean metres; 

338 default is 50 nm. 

339 ensemble_sampling : EnsembleSampling, optional 

340 Realization counts and ordered independent seeds. Defaults to 

341 four consecutive seeds starting at zero. 

342 realizations : int, optional 

343 Deprecated; use EnsembleSampling. 

344 Independent sample count, from 1 to 32. Default is 4. 

345 seed : int, optional 

346 Deprecated; use EnsembleSampling. 

347 First sample seed, from 0 to 2**32 - 1. Default is 0. Samples use 

348 consecutive seeds; the entire seed range must remain valid. 

349 angles : array_like or Quantity, optional 

350 One-dimensional plot angles in [0, pi], with 1 to 181 observations. 

351 Bare values mean radians. Default is 121 evenly spaced angles. 

352 azimuth_samples : int, optional 

353 Uniform azimuth samples for both curves and quadrature, from 4 to 32. 

354 Default is 8. 

355 polar_samples : int, optional 

356 Gauss-Legendre nodes for integration, from 16 to 128. Default is 32. 

357 These nodes are independent of the plot angles. 

358 

359 Returns

367

380

382 -----

384 random amplitudes are never averaged together. Standard errors describe 

385 realization sampling, not spatial or angular discretization error. One 

386 realization gives NaN errors. Numerical integrated coefficients are 

387 finite-sample cross sections divided by volume. Check voxel refinement, 

388 angular quadrature, sample size, and realization count independently. 

389 Deterministic structures have no realization sampling and must use 

390 solve. A single random realization reports unknown sampling errors 

391 (NaN), rather than inferred uncertainty. Individual shape/spacing, angular and realization keywords remain 

392 available with deprecation warnings.
