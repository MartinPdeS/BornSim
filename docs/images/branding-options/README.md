# BornSim identity concepts

Created with the built-in image-generation tool. Each PNG is a concept board
showing a horizontal logo, standalone icon, and favicon study on white.
These are design proposals; production transparent assets have not been installed.

## Prompt set

Shared direction: create a new, refined scientific software identity for BornSim,
a vector electromagnetic Born-series scattering library. Square white board with
a large horizontal symbol and exact BornSim wordmark above, standalone icon and
simplified favicon below. Clean vector-like flat forms, geometric sans typography,
generous space. Avoid atom orbits, decorative particles, mockups, shadows and glow.

1. Wave B: an abstract B built from an incident wave splitting into two broad
   scattering lobes; midnight navy and electric turquoise, bold negative space.
2. Phase lobe: a simplified directional scattering silhouette with a large forward
   lobe and smaller backward lobe; indigo and amber, two or three broad forms.
3. Voxel lens: a cube-like hexagonal silhouette with interlocking planes and a
   wave-shaped negative-space cut; forest green and lime, no fine grid.
4. Interference: two offset broad curved wavefront bands meeting around a central
   aperture; cobalt and coral with a charcoal wordmark, recognizable at small size.
