BornSim branding
================

The selected identity is the refractive-volume concept from the second round.
It uses translucent blue and cyan prism faces, a bending wave, a golden core,
and a custom BornSim wordmark with a gradient Sim suffix. MomentRT's logo was
used as a style reference. Assets were finalized with the built-in image-generation
tool using the approved BornSim concept board as the reference.

Installed assets
----------------

* ``docs/source/_static/logo.png``: transparent horizontal wordmark.
* ``docs/source/_static/icon.png``: transparent standalone symbol.
* ``docs/source/_static/favicon.png``: 256-pixel rounded navy tile with the symbol.
* The SVG files wrap the corresponding PNG images; they are not vector originals.

The exact final prompts are recorded in
``branding-options/selected-refractive-volume-prompts.txt``. Concept boards and
the earlier prompt sets are preserved in ``branding-options``.
