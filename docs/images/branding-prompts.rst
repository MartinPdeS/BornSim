BornSim branding prompts
=======================

Created with the built-in imagegen tool. Both PNG assets retain transparent
backgrounds. The favicon is the symbol; the logo adds the BornSim wordmark.

Favicon prompt
--------------

::

   Use case: logo-design. Create ONE polished standalone favicon and app-icon symbol for BornSim, a scientific Python package for vector electromagnetic Born scattering from random refractive-index media. Output a square transparent PNG. Design a bold, minimal, flat graphic: an abstract capital B constructed from one flowing incident wave ribbon splitting into two rounded scattering lobes around a compact refractive core. Clever restrained scientific identity, no atom-orbit trope, no literal plot axes, no particle confetti. Main color luminous saturated teal #16B8A6 with a smaller sky-cyan accent #39BDF8; strong contrast on both charcoal and white backgrounds. Cohesive silhouette recognizable at 16px. Use very few broad shapes and generous negative space, no thin lines, no gradients, no glow, no shadows, no background plate or border. Center the single symbol, occupy about 85 percent of the square with modest even padding. No text, no other symbols, no mockups or layout sheets. Real transparent background.

Logo prompt
-----------

The generated favicon was supplied as the reference image.

::

   Create a production-ready horizontal BornSim documentation logo lockup on a genuinely transparent background, using the provided graphic as the exact brand-symbol reference. Preserve the teal/cyan wave-scattering B symbol faithfully, do not redesign it. Put this symbol at the left, and a polished bold contemporary geometric sans-serif wordmark at the right. Exact text: "BornSim" with capital B and S, one word, no additional text. Wordmark solid medium teal #0C9695 for visibility on both white and dark charcoal pages. The symbol retains its provided teal and cyan colors. Typography clean professional scientific software, slightly rounded, highly legible, balanced kerning. Wide compact horizontal composition, 3:1 aspect ratio, symbol about 80% of canvas height, wordmark about 55% of canvas height; moderate gap; align optical centers. Fit the artwork closely with only 3% outer transparent padding. Flat crisp shapes, no glows, shadows, outlines, background panels, frames, slogans, mockups, or multiple variants. Output only one complete wordmark logo, not a presentation board.
